# 技能（炼丹房 · 轻量泳道）

产研交付仍走 keel，但必须先选票级泳道，禁止默认套 full 五人仪式。

## 泳道（三选一，开票或开工时写明）

| 泳道 | 适用 | 默认点名 | 流程要点 |
|---|---|---|---|
| `cli-contract` | 公共 CLI/API 契约；无 UI；部署可选 | 苏晴 + 陆深 + 沈予（轻）；周衡只批门；方维仅部署窗打开后进 | 须 L1；L2 可 thin（同 feat 分支）；禁止单独设计合入 PR；开工不点方维 |
| `hotfix` | 已 Approved 设计上的窄回归 | 陆深 + 沈予；周衡批门；苏晴仅范围变化时；方维仅部署时 | 可跳过 how/完整 L1（命中 when-to-write 跳过项）；单 PR |
| `full` | UI / 跨模块 / 预期部署 / 未标明泳道时的默认 | 五人按门禁点名，仍禁止无门齐点 | 完整 keel |

未写泳道 → 按 `full`（保守）。

## 开工点名（周衡）

- 只 @ 本票**已打开**的门禁角色，禁止默认五人齐点。
- 禁止复述整张 Issue：只发链接 +「钉死」要点（至多三条）。
- `cli-contract` / `hotfix` 开工帖不得 @ 方维，除非同帖宣布部署窗打开。

## 观感签收门（2026-09-24）

仅 `full` 泳道且含**用户可见 UI** 的票适用。

合入前（强制）：实现门通过后，**「观感通过」与测试门均须完成**方可进合入门；二者相对顺序不固定。不得跳过，不得以并行冒充完成。

- 签收人：苏晴，或本票负责人（owner）。
- 依据：真机截图，或本地 Console 实看；须在频道回复「观感通过」。
- **禁止**用 L2 设计文档代替真机签收（含「负责人已 Approved 交互」仅落在 markdown 的情形）。
- 未回复「观感通过」前，不得进合入门。
