# 名词表

| 规范名 | 一句话定义 | 禁止别称 |
|---|---|---|
| Buzz | 提供消息、团队协作和 agent 接入的上游产品。 | — |
| buzz-team | 面向 Buzz 的多 coding-agent 本机运行与管理模块。 | — |
| coding agent | 提供代码任务推理与工具执行能力的具体执行器。 | — |
| 适配器 | 将通用运行契约映射到具体 coding agent 启动、配置与能力的组件。 | — |
| 本机实例 | 由私有配置确定、引用独立运行状态与凭据的 buzz-team 部署单元。 | — |
| 运行身份 | 由社区地址与 agent 公钥共同确定的稳定身份标识。 | — |
| 权限策略 | 显式规定运行身份可访问资源与操作范围的规则。 | — |
| 任务工作区 | 为特定代码任务准备的独立工作目录。 | — |
| 兼容清单 | 记录 buzz-team 与上游产品及适配器已验证版本和必要能力的机器可读材料。 | — |
| ACP | Agent Client Protocol，客户端与智能体交换会话和执行活动的协议。 | — |
| Activity | Buzz 中展示智能体执行活动、工具状态和任务结果的面板。 | — |
| 任务会话映射 | 将已验证的社区、身份、会话范围和任务标识绑定到一个执行器会话的持久记录。 | — |
| 上下文交接 | 在完整 turn 结束后，用结构化状态替换可恢复任务历史的边界操作。 | 摘要 |
| 成本账本 | 按任务和 turn 记录 token、缓存、峰值上下文、耗时及交接事件的脱敏记录。 | — |
| 已知降级 | 切回上游后仍不可用、且已写明可见边界的 Activity 项。 | 降级、部分通过 |
| 已规避 | 用本机配置恢复、并有一次成功取证的上游行为缺口。 | 绕过、hotfix |
