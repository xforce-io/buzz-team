# r2 self-signed negative (Knox P2). Two parts: (A) box re-sign with rcodesign, (B) Mac run of docs/issue-58/selfsigned-negative.sh

## A. why a second signer, and how the copy was made (box, Linux, 2026-09-30 14:02 CST)
On the Mac, codesign refused both identity forms from the temporary keychain file (see B §3: 'no identity found' by
name and by SHA-1; find-identity lists it as CSSMERR_TP_NOT_TRUSTED). Adding the keychain to the search list or
trusting the cert was out of bounds, so the same kind of cert was used with rcodesign (apple-codesign 0.29.0,
github.com/indygreg/apple-platform-rs release binary) on the box, which signs from PEM files without a keychain:
  openssl req -x509 -newkey rsa:2048 -nodes -sha256 -days 1  (same cert.cnf as selfsigned-negative.sh:
    CN=buzz58 r2 self-signed test (not Apple), OU=EYF346PHUG, O=buzz58-r2-test; EKU critical codeSigning)
  subject=issuer=CN=buzz58 r2 self-signed test (not Apple), OU=EYF346PHUG, O=buzz58-r2-test
  cert sha1=38:55:9A:EC:DC:99:2E:68:54:07:4D:43:B3:BC:15:58:ED:FA:F9:96
  rcodesign sign --pem-file key.pem --pem-file cert.pem --binary-identifier buzz --team-name EYF346PHUG <copy of official buzz>
    input  sha256=bbabc37d36907411e0b90a5789b2642ba4fcebb34bdd2ffff2414696d54052ba (official 0.5.25, copied from the Mac)
    rcodesign: 'signing without an Apple signed certificate but signing settings contain a team name'; rc=0
    output sha256=0b9afb32ad580e50d9a9a763c53441a4bd06ea59b443c92fd89c239a1117720d
  rcodesign print-signature-info: identifier: buzz, team_name: EYF346PHUG, designated: identifier "buzz" and certificate root = H"38559aec…f996"
The private key was deleted right after signing. The signed copy was shipped to the Mac temp dir as a byte delta against
the official binary (4 header bytes + 143088-byte signature tail) and rebuilt there with sha256 checks on input and output
(result: ok 0b9afb32…720d); it was then passed as SELFSIGNED_PRESIGNED. The temp keychain part still ran in full.
A first Mac run at 13:59 (before SELFSIGNED_PRESIGNED existed) hit the same codesign failure and then ran §4–5 on the
UNMODIFIED copy, so those lines were meaningless; that run was discarded and the script now skips §4–5 unless the copy
differs from the official binary.
