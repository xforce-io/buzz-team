# 迁移与恢复（S3）

先跑临时文件的 bind/rollback、进程存活拒绝和并发配置变更拒绝。真实实例先记录配置与认证路径、inode，再 prepare/doctor；认证保持原地，禁止复制或恢复。客户端空闲后停止并 bind，启动后检查绑定和行为。预览结束按 runbook 回退，确认原绑定可恢复且认证文件未由迁移更换；不得用旧 OAuth 内容覆盖正常刷新。

残留执行器（包括解释器启动的 ACP 命令）也须阻止绑定；回退须还原原本缺失的 env_vars 容器，同时保留迁移后新增的无关设置。

切换适配器并删除旧配置后，现有绑定的旧执行器及身份工作目录中的未知/改名进程仍阻止绑定；其他工作目录中的无关进程不因此被视为身份任务。

实例与生产数据根的相等、包含、被包含均拒绝；init拒绝时不得留下部分实例。
